# Bootcamp 2026: Dota 2 Data Engineering & Analytics

Этот репозиторий содержит материалы и реализацию аналитических кейсов по данным матчей Dota 2.

## 📂 Структура репозитория

Репозиторий разделён на две основные версии, отражающие эволюцию проекта от исследовательского прототипа к production-ready решению.

### `VERSION_1/` — Артефакты буткемпа (Research & Documentation)
Содержит исходные исследовательские материалы, созданные в рамках буткемпа:
- Jupyter Notebooks с EDA, статистическими проверками гипотез и прототипами кода.
- Полная библиотека Governance-документации (Data Dictionary, MRM Policy, Data Lineage Spec, Incident Response Runbook, Access Control Matrix, SLA).
- Спецификации Data Quality и описания источников данных.
*Эта версия служит источником требований и бизнес-логики, но не предназначена для прямого развёртывания.*

### `VERSION_2/` — Production-реализация (DataOps & Engineering)
Технически улучшенная, модульная и автоматизированная версия проекта, реализующая принципы Medallion Architecture (RAW → STAGE → MART) на базе современного стека DataOps.

**Реализованный кейс:** 
На текущий момент полностью реализован **Кейс №3: Влияние убийства Рошана на исход матча** (включая генерацию данных, ETL-пайплайн, DQ-проверки и оркестрацию). Остальные кейсы из `VERSION_1` запланированы к переносу по аналогичному шаблону.

**Технический стек VERSION_2:**
- **Оркестрация:** Apache Airflow (DAGs с TaskGroup по слоям).
- **Обработка:** Apache Spark (PySpark) с интеграцией OpenLineage.
- **Хранение:** Apache Iceberg поверх MinIO (S3-compatible).
- **Источники:** PostgreSQL (структурированные данные), MongoDB (события).
- **Генерация данных:** Кастомный генератор на Rust (`data-gen/`), обеспечивающий воспроизводимую генерацию тестовых данных, строго соответствующих схеме.
- **Аналитика:** Trino (SQL-движок) + Apache Superset (BI-визуализация).
- **Наблюдаемость:** Marquez (Data Lineage).

## 🚀 Быстрый старт (VERSION_2)

Для развёртывания всей инфраструктуры и запуска пайплайна:

1. Перейдите в директорию `VERSION_2`:
   ```bash
   cd bootcamp2026-notebooks/VERSION_2
   ```

2. Скопируйте переменные окружения (при необходимости отредактируйте `.env`):
   ```bash
   cp .env.example .env
   ```

3. Запустите инфраструктуру (включая генератор данных, Airflow, Spark, Trino, Superset и Marquez):
   ```bash
   docker compose --profile base --profile etl --profile compute --profile bi --profile lineage up -d
   ```

4. Дождитесь инициализации сервисов (около 1-2 минут) и проверьте статус:
   ```bash
   docker compose ps
   ```

5. Запустите генерацию тестовых данных (опционально, если нужен свежий набор):
   ```bash
   # Генератор можно запустить вручную или через предусмотренный DAG
   docker compose run --rm generator --matches 1000 --seed 42
   ```

6. Откройте веб-интерфейсы:
   - **Airflow:** http://localhost:8081 (admin / admin)
   - **Superset:** http://localhost:8088 (admin / admin)
   - **Marquez:** http://localhost:5000

## 🛡️ Комплаенс и качество данных

Проект строго следует принципам Data Governance, описанным в документах:
- [`COMPLIANCE-ru.md`](./COMPLIANCE-ru.md) — Описание мер по обеспечению качества, безопасности и наблюдаемости данных (на русском).
- [`COMPLIANCE-en.md`](./COMPLIANCE-en.md) — Compliance and Data Governance overview (in English).

**Важное примечание:** Документация по комплаенсу отражает **только реально реализованные** в `VERSION_2` механизмы. Например, инкрементальная загрузка (`MERGE INTO`) реализована только на слое RAW; слои STAGE и MART используют полный пересчёт (`createOrReplace`) для гарантии целостности агрегатов. Механизмы криптографического шифрования данных в покое не применяются в рамках данного учебного проекта.
